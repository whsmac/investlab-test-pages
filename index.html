투자 분석 대시보드

5개 주요 메뉴를 중심으로 기능을 확인할 수 있습니다. 현재는 TEST 파일럿 준비 단계이며, 메뉴별로 데이터 연결과 온라인 검증 상태가 다릅니다.

1. My Portfolio

보유·관심·거래이력 종목 및 계좌 데이터 연결 상태 확인

● 읽기 전용 연결 점검 · 운영 기능 미완성

2. Virtual Trade Simulator

가상 매수·매도 전략과 계좌별 손익 비교

● 브라우저 기반 · 서버 동기화 미검증

3. Company Investment Analysis

6개 기업의 주가·분기 재무 관측값 조회

● TEST 공유 데이터 조회 기능

4. Unified Ledger

계좌별 거래 원장·보유종목·현금잔고 검토

● 예시 JSON 기반 · 서버 연동 전

5. Data Management

계좌별 원장 대조 및 JSON 검토 결과 관리

● 임시 검증 화면 · 자동 수집·공유 저장 미완성

공통 주가 차트 TEST 미리보기 (CSV 없이 서버 조회)

주가 수집 데이터와 TEST DB 대조 (읽기 전용)

보조 검증 도구 펼치기

계좌별 초기잔고 배정

보유종목과 USD·KRW 현금잔고를 계좌별로 검토

● 오프라인 검증 전용

원장 잔고 대조

계좌별 포트폴리오와 원장 계산 결과를 비교하고 JSON 보고서 저장

● 오프라인 검증 전용
안전 안내: 이 사이트는 TEST 전용입니다. 운영 데이터 변경이나 실제 주문 기능은 제공하지 않습니다. Supabase service_role 키 또는 비밀번호를 소스코드에 저장하지 마세요. 공유 데이터 CSV 가져오기 화면은 아직 배포되지 않았습니다.
