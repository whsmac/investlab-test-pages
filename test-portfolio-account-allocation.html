기존 보유종목을 계좌별로 배정하고 현금잔고를 별도 지정합니다. JSON 입력값은 브라우저 내부에서만 처리하며 서버에 전송하지 않습니다.

1. 보유종목 파일과 계좌 등록

기존 포트폴리오에서 내보낸 JSON 파일을 선택하면 보유종목을 불러옵니다. 계좌는 직접 등록해야 하며, 종목별 계좌 배정과 실제 취득원가는 확인 후 입력합니다.

고급 입력 · JSON 보기/수정

기존 보유종목 내보내기 JSON

계좌 목록 JSON (계좌 UUID·이름·소유 확인)

종목별 계좌 배정 JSON

계좌별 USD/KRW 현금 JSON

계좌별 실제 취득원가 확인 JSON (각 종목·계좌의 원가와 소유 확인 필수)

2. 계좌별 수량·원가·현금 입력

위 JSON의 기존 보유종목과 계좌를 읽어 표를 생성합니다. 종목별 계좌 배정·수량·실제 취득원가를 입력한 뒤 JSON 입력란으로 반영할 수 있습니다.

계좌별 배정표를 생성하면 종목별 미배정 수량을 확인할 수 있습니다.

최종 점검을 실행하면 미확인 항목을 종합합니다.

3. 검증 및 결과 저장

4. 이전 검토 결과 비교

이전 검토 파일을 선택하면 현재 입력과 비교합니다. 파일을 선택해도 자동 이관하거나 승인하지 않습니다.

5. 계좌별 검증 결과

아직 검증하지 않았습니다.

표의 일치는 브라우저 내부의 수량 대조 결과이며 서버 검증이나 실제 이관 승인이 아닙니다.
