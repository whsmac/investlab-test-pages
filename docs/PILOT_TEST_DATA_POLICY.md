# INVESTLAB 1단계 Pilot — TEST 입력 데이터 처리 원칙

최종 사용자 요청: 2026-11-21.

## 사용자 승인 범위
- 사용자가 INVESTLAB **TEST 환경**에 직접 등록한 시험용 계좌, 보유종목, 수량, 거래, 현금, 시나리오 및 관련 입력 데이터는 **임시 자료**다.
- TEST 기능 개발·수정·재구성·오류 해결 과정에서 **이러한 시험 데이터는 초기화하거나 삭제해도 된다**. 보존 때문에 개발을 지연할 필요는 없다.
- 초기화 후 데이터 재입력이 필요할 수 있다는 점을 사용자가 인지하고 있다.

## 경계와 개발 원칙
- 위 허용은 **사용자 본인의 TEST 입력자료**에 한정한다. 운영용 데이터, 타 사용자의 데이터, 접근권한 설정이나 Supabase 스키마 변경까지 허용하는 뜻이 아니다.
- 특히 `whsmac/investlab-dashboard` 운영 저장소와 운영 Supabase는 기존 변경 금지 원칙을 유지한다. TEST DB 구조·권한 변경이나 PR 병합 역시 별도 지시가 없는 한 진행하지 않는다.
- 실질적인 TEST 자료 삭제·초기화가 필요한 경우 해당 범위와 결과를 사용자에게 명확히 알린다.
- 우선순위는 **1단계 Pilot의 빠른 온라인 실사용·기능 완성**이다. 불필요한 데이터 보존 호환 작업이나 자동검증 기능 추가로 Pilot을 지연시키지 않는다.
- 2단계 AI 개발 아이디어는 별도 백로그로 관리한다.

이 문서는 개발 기준을 기록하며 **실제 데이터 삭제·초기화·DB 수정 명령을 수행하지 않는다**.
