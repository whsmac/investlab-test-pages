## 개선사항
- 계좌, 거래 이벤트, 거래 legs를 단일 SQL 트랜잭션에서 생성
- 인증 사용자에게 SELECT만 부여하고 직접 INSERT/UPDATE/DELETE 차단
- 함수 생성과 PUBLIC/anon EXECUTE 철회를 같은 트랜잭션에서 수행
- 복합 FK로 다른 사용자의 계좌·이벤트 참조 방지
- 요청 ID 중복 처리, 동일 계좌 직렬화, USD 현금/주식 부족 거부
- 서버에서 양쪽 leg를 원자적으로 저장. 함수는 매수·매도만 지원

## 배포 차단 사유 (반드시 해결)
1. **기초 잔고 입력 기능이 없어 신규 계좌는 매수할 수 없음**. 계좌 생성도 아직 읽기 전용
2. 기존 보유·현금 데이터 이전과 검증되지 않은 SECURITY DEFINER 소유자/권한
3. 과거 시점 거래 삽입 시 중간 시점의 잔고 음수 가능; 이벤트 정정·역거래 미구현
4. 취득원가·양도세·수수료·KRW 환전·배당·입출금 미구현
5. RLS A/B/anon PostgREST 테스트, 실제 동시 요청 테스트, 롤백 테스트 미실시
6. 기존 TEST 테이블/함수 이름 중복 확인 및 TEST 프로젝트 ID 확인 필요
7. DB 소유자/특권 역할의 직접 쓰기는 REVOKE만으로 차단되지 않음
