① 아래 계좌 선택 → ② JSON 파일 선택 → ③ 기존 보유종목 확인 순서로 진행하세요.

기존 TEST 사이트에서 내보낸 JSON 파일을 선택하면 보유종목과 선택한 계좌의 원장 잔고를 비교합니다. 실제 원장에는 반영하지 않습니다.

같은 주소의 브라우저 저장소만 읽습니다. 다른 주소의 기존 포트폴리오 데이터는 자동 접근할 수 없습니다.
