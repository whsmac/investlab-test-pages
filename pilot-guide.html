1단계 PILOT · 초보자 가이드

계좌 등록부터 가상거래·기업분석까지

처음 이용할 때는 아래 순서대로 진행하세요. 실제 주문은 실행되지 않으며, 입력한 계좌·거래·전략은 TEST 환경의 자료입니다. 모든 기능을 한꺼번에 익힐 필요는 없습니다.

① 로그인② 계좌·거래③ 보유현황④ 가상거래⑤ 기업분석⑥ 백업
STEP 1

TEST 계정으로 로그인

  1. 홈페이지의 TEST 계정 연결·로그인을 누릅니다.
  2. 기존에 연결한 TEST 프로젝트의 공개용 키와 본인 계정으로 로그인합니다. service_role·secret 키는 사용하지 마세요.
  3. 로그인 완료 안내를 확인한 뒤 통합원장으로 이동합니다.
TEST 계정 연결·로그인
STEP 2

통합원장에 계좌와 거래 입력

  1. Unified Ledger → 계좌 등록에서 계좌 이름과 종류를 정하고 계좌 추가를 누릅니다. 실제 증권계좌 번호나 비밀번호를 입력할 필요는 없습니다.
  2. 원장 입력에서 계좌와 날짜를 고른 다음 거래 종류를 선택합니다.
  3. 현재 보유수량을 시작값으로 등록한다면 초기 보유 입력으로 종목·수량·평균매입단가(USD)를 입력합니다. 현재 현금은 현금 입금으로 별도 입력합니다.
  4. 이후 새로 발생한 거래는 매수 또는 매도를 선택해 수량과 주당 가격을 기록합니다. 필요한 경우 배당금 수령·현금 출금·환전도 거래 종류에서 선택할 수 있습니다.
  5. 거래 기록을 누른 다음 화면 아래 보유현황과 거래내역을 확인합니다. 온라인 연결 상태의 서버 자동 저장 완료 안내도 확인하세요.
중복 입력 주의: 오늘 기준 TSLA 10주를 '초기 보유 입력'했다면, 그 10주를 구성한 과거 매수를 다시 입력하지 마세요. 초기 보유 기준일 이후 발생한 거래만 추가해야 수량이 중복되지 않습니다. 현재 1단계의 USD 실현손익은 증권사 세무신고 기준 손익과 다를 수 있습니다.
Unified Ledger 열기
STEP 3

My Portfolio에서 보유현황 확인

  1. 통합원장에 기록한 종목·수량·평균매입단가·현금을 다시 입력할 필요가 없습니다.
  2. My Portfolio에서 계좌별/전체 계좌 기준으로 보유수량, 평균매입단가, USD 현금 및 최근 종가 기반 평가금액을 확인합니다.
  3. 수량이나 평균단가가 맞지 않다면 이 화면에서 다시 입력하지 말고 Unified Ledger의 거래 기록을 수정하세요.
My Portfolio 열기
STEP 4

Virtual Trade Simulator로 가상 매수·매도

  1. 현재 투자현황의 계좌 기준을 정하고 선택 계좌를 가상매매 시작값에 적용을 누른 뒤 확인합니다.
  2. 시작 보유수량과 USD 현금을 확인합니다. 필요하면 최근 종가로 빈 가정주가 채우기를 사용하고, 미래 가정주가는 직접 조정합니다.
  3. + 거래 추가에서 가상의 매도 또는 매수, 종목, 수량 및 가정 체결가격을 입력합니다.
  4. 시나리오 계산 · 결과 갱신을 눌러 최종 보유수량, 현금흐름, 실현손익과 평가금액 차이를 비교합니다.
  5. 전략 이름을 정하고 현재 전략 저장을 누릅니다. 나중에는 저장 목록에서 골라 선택 전략 불러오기를 사용하세요.
시뮬레이터의 거래는 실제 통합원장의 매수·매도 내역을 변경하지 않습니다. 저장 전략을 다시 열면 현재 계좌의 시작 보유정보와 가정주가를 확인하고 계산을 다시 실행하세요.
Virtual Trade Simulator 열기
STEP 5

Company Investment Analysis에서 기업 재무 검토

  1. 상단에서 MSFT·GOOGL·AMZN·META·TSLA·SPCX 중 비교할 기업을 복수 선택합니다.
  2. 조회 기간을 3년 또는 5년으로 변경하면 복수 종목 주가를 각 종목 시작점 100 기준으로 비교할 수 있습니다.
  3. 재무·요약 기준 종목을 바꾸면서 한 기업의 분기별 매출액, CAPEX, 영업이익, 영업이익률을 같은 날짜 축에서 검토합니다.
  4. 하단 분기 재무자료 표로 정확한 표시값과 누락 구간을 확인합니다.
주가는 최근 게시된 종가로 실시간 호가가 아니며 배당 총수익률을 포함하지 않습니다. TEST 분기 재무자료와 SEC 자동수집 자료의 공식 공시 대조는 별도로 확인해야 합니다.
Company Investment Analysis 열기
STEP 6

Data Management에서 백업

  1. Data Management에서 현재 로그인 계정의 브라우저 저장 전략·임시작업을 확인합니다.
  2. TEST 서버 포함 전체 백업을 누르면 개인 원장과 저장 전략 등을 JSON 파일로 내려받습니다.
  3. 다운로드한 파일을 보관합니다. 복원 버튼은 기존 자료를 교체할 수 있으므로 복원이 필요할 때만 사용하세요.
