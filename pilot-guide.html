1단계 PILOT · 초보자 가이드

계좌 등록부터 가상거래·기업분석까지

처음 이용할 때는 아래 순서대로 진행하세요. 실제 주문은 실행되지 않으며, 입력한 계좌·거래·전략은 TEST 환경의 자료입니다. 모든 기능을 한꺼번에 익힐 필요는 없습니다.

① 로그인② 계좌·거래③ 보유현황④ 가상거래⑤ 기업분석⑥ 백업
STEP 1

HOME에서 로그인

  1. INVESTLAB 홈의 로그인 영역에 계정 이메일과 비밀번호를 입력하고 로그인을 누릅니다.
  2. 공개용 TEST 연결은 자동 설정됩니다. 이메일과 비밀번호만 입력하면 됩니다. 연결 문제가 있을 때만 고급 연결 설정을 사용하세요. secret/service_role 키는 사용하지 않습니다.
  3. 로그인 상태가 확인되면 계좌·매매 기록 관리로 이동합니다. 다른 주요 모듈에서도 로그인 상태가 유지됩니다.
HOME 로그인
STEP 2

계좌·매매 기록 관리에서 거래 입력

  1. 계좌 관리에서 계좌 이름과 종류를 정하고 계좌 추가를 누릅니다. 계좌번호나 증권사 비밀번호는 입력하지 않습니다.
  2. 거래 입력 맨 위에서 계좌를 선택하고 날짜와 거래 종류를 정합니다.
  3. 종목은 보유종목 / 관심종목 / 기 보유·매매종목 / 직접입력 중 선택합니다. 신규 종목은 직접입력으로 등록할 수 있습니다.
  4. 보유수량을 시작값으로 등록할 때는 초기 보유 입력을 고르고 종목·수량·평균매입단가(USD)를 입력합니다. 현금은 현금 입금으로 별도 입력합니다.
  5. 이후 발생하는 매수·매도를 기록합니다. 양도소득세 납부는 별도 거래 유형이 아니라 현금 출금을 선택하고 메모에 납부 사실·귀속연도를 기재합니다. 실제 출금된 계좌에만 기록하세요.
  6. 환전할 때는 실제 지출금액과 수령금액을 입력합니다. 수수료가 포함된 유효환율을 자동 계산하여 함께 저장합니다. 예: KRW 13,690 지출 → USD 10 수령 = 1,369 KRW/USD.
  7. 저장을 누르고 서버 저장 상태를 확인합니다. 거래내역은 최근 5건씩 표시되며 시작·종료일로 기간 조회할 수 있습니다. 거래 수정·삭제는 거래내역의 버튼에서 진행합니다.
중복 입력 주의: 현재 보유 10주를 초기 보유로 등록했다면 이를 구성한 과거 매수내역을 다시 등록하지 마세요. 주식 실현손익과 양도세 실제 납부액은 서로 다른 정보입니다.
계좌·매매 기록 관리 열기
STEP 3

내 투자현황에서 보유현황 확인

  1. 계좌·매매 기록 관리에 기록한 종목·수량·평균매입단가·현금을 다시 입력할 필요가 없습니다.
  2. 내 투자현황에서 계좌별/전체 계좌 기준으로 보유수량, 평균매입단가, USD 현금 및 최근 종가 기반 평가금액을 확인합니다.
  3. 수량이나 평균단가가 맞지 않다면 이 화면에서 다시 입력하지 말고 Unified Ledger의 거래 기록을 수정하세요.
내 투자현황 열기
STEP 4

가상매매 시뮬레이터로 가상 매수·매도

  1. 현재 투자현황의 계좌 기준을 정하고 선택 계좌를 가상매매 시작값에 적용을 누른 뒤 확인합니다.
  2. 시작 보유수량과 USD 현금을 확인합니다. 필요하면 최근 종가로 빈 가정주가 채우기를 사용하고, 미래 가정주가는 직접 조정합니다.
  3. + 거래 추가에서 가상의 매도 또는 매수, 종목, 수량 및 가정 체결가격을 입력합니다.
  4. 시나리오 계산 · 결과 갱신을 눌러 최종 보유수량, 현금흐름, 실현손익과 평가금액 차이를 비교합니다.
  5. 전략 이름을 정하고 현재 전략 저장을 누릅니다. 나중에는 저장 목록에서 골라 선택 전략 불러오기를 사용하세요.
시뮬레이터의 거래는 실제 계좌·매매 기록 관리의 매수·매도 내역을 변경하지 않습니다. 저장 전략을 다시 열면 현재 계좌의 시작 보유정보와 가정주가를 확인하고 계산을 다시 실행하세요.
가상매매 시뮬레이터 열기
STEP 5

기업 투자분석에서 기업 재무 검토

  1. 상단에서 MSFT·GOOGL·AMZN·META·TSLA·SPCX 중 비교할 기업을 복수 선택합니다.
  2. 조회 기간을 3년 또는 5년으로 변경하면 복수 종목 주가를 각 종목 시작점 100 기준으로 비교할 수 있습니다.
  3. 재무·요약 기준 종목을 바꾸면서 한 기업의 분기별 매출액, CAPEX, 영업이익, 영업이익률을 같은 날짜 축에서 검토합니다.
  4. 하단 분기 재무자료 표로 정확한 표시값과 누락 구간을 확인합니다.
주가는 최근 게시된 종가로 실시간 호가가 아니며 배당 총수익률을 포함하지 않습니다. TEST 분기 재무자료와 SEC 자동수집 자료의 공식 공시 대조는 별도로 확인해야 합니다.
기업 투자분석 열기
STEP 6

설정에서 백업·복원

  1. 상단 공통 메뉴의 설정 · 백업을 선택합니다.
  2. 백업 파일 저장을 누르면 현재 로그인한 계정의 서버 계좌·거래·저장 전략과 해당 기기 임시 작업을 하나의 JSON 파일로 다운로드합니다.
  3. 복원이 필요할 때는 백업 파일 선택 후 내용을 확인하고 서버에 복원을 사용합니다. 복원 전에 최신 파일을 별도 백업하세요.
